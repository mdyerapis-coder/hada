# M0 Milestone Report — Governed Foundation

## Scope completed

- HADA/Hermesctl system boundary documented
- enforceable party and gate model implemented
- self-approval prevention tested
- independent external-review stop implemented
- Ubuntu 24.04 bootstrap and host validation supplied
- PostgreSQL, Valkey, Prometheus, Grafana, Loki, Caddy and node-exporter base stack supplied
- bounded watchdog recovery supplied
- CI, type checking, linting and tests supplied
- architecture, RFCs, ADRs, roadmap and runbooks supplied

## Known limitations

M0 does not yet implement the durable database orchestrator, inference services, signed evidence bundles, restricted tool broker, Hermesctl mutation workflow or external decision import. Those are deliberately assigned to later milestones.

## Governance outcome

Internal implementation artefacts are ready for Party 2 review. Party 3 review remains a mandatory external stop condition. M1 must not begin until the target repository and approved model profiles are configured and M0 receives the required approvals.
